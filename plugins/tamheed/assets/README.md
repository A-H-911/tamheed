# Assets

The Tamheed brand marks, maintainer-selected. The mark has two halves: three ascending paving
steps, then a flat slab, with an arc returning to the first step. Beside it stands the bilingual
Tamheed / تمهيد wordmark. Four SVGs: `logo.svg`, `logo-dark.svg` and `logo-light.svg` are the
full lockups per background, `icon.svg` is the mark alone. Nothing in the repo references it today. The repo README and
the user guide's header read the lockups. Not read at runtime. The drawing they are emitted
from is `plans/evidence/scripts-209/make_209_assets.py`.
